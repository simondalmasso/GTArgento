# Asset Sources — ORDER-001

## Shipped third-party geometry

- `public/assets/moria-base.glb` — Quaternius **Universal Base Characters / Universal Animation Library** humanoid rig and animation set, CC0 1.0 / public-domain dedication. The file was materialized from the pre-existing `fastrouter/experiments-costa-vista` bundle used by the ARQ probe; its attribution identifies the Quaternius CC0 packs. Production runtime substantially restyles the rig with original geometry/materials for Moria's head, facial features, hair, dress, coat silhouette and accessories.
  - Upstream packs: https://quaternius.com/packs/universalbasecharacters.html and https://quaternius.com/packs/universalanimationlibrary.html
  - Bundle source used for the exact GLB: https://github.com/fastrouter/experiments-costa-vista/blob/main/public/assets/characters.glb
  - License: CC0 1.0

## Original runtime art

All Buenos Aires/Corrientes architecture, street layout, signs, theatre marquees, Obelisco silhouette, kiosco, taxi styling, colectivo cue, NPC props, HUD, Q shockwave, lighting/glow treatment and Moria-specific fashion/face/hair geometry are authored procedurally in this repository. No GTA/Rockstar assets, logos, maps, fonts, audio or ripped content are bundled.

## Audio

The Q impact sound is synthesized at runtime with Web Audio. No third-party voice, music or audio file is shipped.
